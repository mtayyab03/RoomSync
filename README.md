# Roomsync

A starter React Native app built with Expo and TypeScript.

## Requirements
- Node.js (LTS)
- npm
- Expo Go on a phone, or an iOS/Android simulator

## Run locally

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go, or press `i` for the iOS simulator,
`a` for the Android emulator, or `w` for web.

## Project structure

```text
Roomsync/
├── App.tsx
├── app.json
├── package.json
├── tsconfig.json
└── README.md
```

The first screen is a simple shared-home dashboard placeholder. Replace
the sample tasks and add navigation, authentication, and data storage as
the product requirements take shape.
